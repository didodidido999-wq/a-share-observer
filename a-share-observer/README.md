## 数据任务（2026-06-10 归档起点）

- **一次性回补：** GitHub Actions → `Update A-share dashboard` → `Run workflow` → `mode: backfill`。通过同花顺全市场10年未复权Parquet获取 **2026-06-10 至今** 的全市场每日统计；指数、行业及概念指数通过历史K线接口一次拉取相应区间；涨停股票池按交易日查询。旧数据若已经归档，尽可能复用，不覆盖已核实指标。
- **日常更新：** 主采集计划北京时间工作日 16:07、16:49，代表股 16:18，板块 16:34、17:09，恢复任务 17:26、18:16。调度可能延迟，程序使用交易日历选择最近已收盘交易日（16:00 后）；周末、节假日和次日凌晨不再按“今天还没收盘”空跑成功。
- **缺失与补采：** 当日仅取日期匹配的收盘快照；跨日只用带日期的历史日线，不把现有快照冒充历史。近九个已收盘交易日内的缺档使用滚动 10 日包、历史指数/板块 K 线和按日期涨停池定向补录。常规已完整归档日期复用，不重复下载；超出窗口应人工评估完整历史回补。
- **完成判据：** 恢复验证目标日期的基础归档、代表股当日覆盖以及板块成员衍生质量；跳过或沿用旧日期不等于恢复成功。历史特色字段不能可靠还原时保持缺失，质量状态不会伪装为完整。
- **离线重建：** `mode: rebuild` 仅从已有归档重建索引和看板，不能生成缺失交易日。


## 数据文件

- `a-share-observer/docs/data/history/YYYY-MM-DD.json`：每日行情、指标、涨停股详情、板块数据（长期按日归档）。
- `a-share-observer/docs/data/dates.json`：所有已归档交易日期、存储占用、历史起点。
- `a-share-observer/docs/data/dashboard.json`：仅最近10个交易日的快速加载视图，不包含全部历史。
- 网页可以自由选择起止日期；首次打开默认最近10个交易日。选择历史区间时仅下载选中的日归档文件，并发请求数限制为6，板块矩阵每页60个板块。

历史板块涨停归因若缺乏**当时**成分股数据则留空；不能用最新成分股伪造2026年6月的历史归属。历史特色数据能否回补取决于同花顺实际接口返回。

## 大盘环境与个股风险观察

新增风险工作区只展示已采集的事实与透明规则，不输出买卖指令或“安全分数”。个股可按代码/名称搜索，未找到意味着本次目录没有收录，不意味着不存在或没有风险。缺失来源、未披露数据和非适用品种必须区别展示；不得把缺失填零。

- 大盘环境使用独立发布的利率/债券收益率序列及已有融资观察。利率单位为%，相邻观察值变化单位为bp（1个百分点=100bp）。货币利率不等于股票资金净流入，国债收益率不等于债券价格。
- 个股融资是未偿还杠杆头寸与已披露买入/偿还事实，不代表“主力”或全部散户；交易日期不等于实际公布时间。未验证历史公布时间的记录不能用于声称14:45可获得的无前视回测。
- 关联转债、场外风险、权证或分离债仅在有可靠可用数据时判断，不根据查不到记录判定“无风险”。价格、成交额观察也不能替代公司公告、财报和偿债能力调查。
- 风险数据独立采集：首页仅请求轻量 `risk-macro.json`，进入个股页面加载 `risk-observer.json` 目录，选中股票后按需请求 `risk-stocks/代码.json`。工作流输出验收产物并将验证数据写回当前功能分支或 main；功能分支不会更新生产分支。与已有常规写入任务共享串行组，避免互相覆盖。
- 初始融资采集覆盖最近披露日附近的短窗口，后续保留已观察历史，不等于全历史回补。沪深披露日期可能不同，查询严格按所选日期，不用前一天替代缺失。当前证券目录不能替代历史成分目录。

### 阅读顺序与时间口径

风险工作区按“关注事项 → 融资变化 → 同股对照 → 披露事件 → 数据覆盖”组织，而不是把所有字段当作同等风险评分。余额看存量趋势，净买入看正负流量，比例只与同股前一有效观测比较；事件同时保留公告日与发生日。未触发和查无记录都不代表安全。

新增的转债关联与生命周期只作为最新抓取快照核查，不还原历史有效转股价，不计算未校准的转股溢价。质押统计日不代表实际公布时点。股东增减持记录是已披露变动，不是尚未执行的减持计划。研究页是盘后归档，不是14:45实时决策终端。

风险采集每天北京时间19:20尝试更新（含周末披露），各来源独立报告成功/失败和日期；来源失败时保留旧证据并明确陈旧状态。此流程不承诺尚无可用来源的字段已完成每日人工检索或补录。
