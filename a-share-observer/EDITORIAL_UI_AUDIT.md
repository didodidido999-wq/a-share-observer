## 结构变化

- 全局海报删除，精确 slogan 仅在研究页内容末尾低调出现一次；其他页面不可见。
- 全站工具栏、页面标题与日期压缩为一套信息层级。成功加载长提示不再抢首屏，失败与数据警告仍保留。
- 大盘：四项真实数值 → 简短日期前后操作 → 指数/成交图 → 可展开历史回放和双日期比较 → 完整广度/明细。所有历史控件、DOM ID、深链保留。
- 研究：综合判断/反证与真实跨市场数值优先，旧规则归档独立折叠。由研究模块实现，不能用 CSS 冒充新增证据。
- 政策：桌面事实与日程双工作区；手机先事实后日程，不强挤两列。
- 个股：压缩查询与说明容器，不去除风险缺口，不改风险判定。
- 白/浅灰数据台、深墨文字与蓝色交互，不再金色大标题或普通提示加金边。重要控件至少 12px，正文 13px 起，数字优先。
