# 大盘研究与判断：运行、边界与复盘

本模块是可审计的规则辅助研究，不是已验证的预测模型，不自动交易或改变用户的仓位体系。

## 每日运行

```
python scripts/research_ledger.py
python scripts/research_ledger.py --check
```

只读 `docs/data/history/*.json`，跳过当前时间之后生成的归档以及尚未收盘日期。主方向用沪深300最近5个归档间隔动量与最新全市场上涨覆盖：动量正且覆盖≥55%为偏强，动量负且覆盖≤45%为偏弱；否则暂不判断。数据超过4个自然日则新生成规则判断 abstain。原预测永不追改，网页另提示陈旧。

版本 `breadth-trend-v1`，变更规则/阈值必须升级版本并记录原因，不为改善既有命中数改变历史标签。主5交易日类别边界固定±1%，辅助1日±0.5%、20日±2%，等于边界计震荡。辅助期限只是结果观察，不计为已经预测了方向。阈值为预设研究口径，不是假称由最优回测选择。

同一data_date和model_version不重复新增预测；旧预测和已完成评价不覆盖。宏观/政策/资金背景独立更新，明确不属于旧预测冻结输入。缺失不等于零。

## 先公开，再激活

`issued_at`是生成时间，不能当作真实上线时间。第一次生成未激活，不能计入前瞻成绩。运维先从**线上**研究JSON确认 exact forecast ID、原始输入及版本已公开，随后运行：

```
python scripts/research_ledger.py --activate --activate-id research-实际已验证ID
```

激活新增单独activation事件，不改forecast。命令必须显式ID；不把daily新生成的最新记录自动激活。再次发布包含该激活事件的JSON。未验证线上内容时不要运行activate。未来每日发布也遵守此过程；如果部署确认回调未设置，记录保持未激活而非假称已形成前瞻样本。

指标变化的参照是生成时已知沪深300收盘值，不是可成交价格。到期日为**激活日期之后**第1/5/20个完整交易日，日期由核验日历确定。因此激活晚于生成会包含中间行情，操作者应在同一发布窗口激活；延迟跨越交易日应生成新版研究再发布，不能激活陈旧研究。交易执行收益未实现，不能把指数方向命中当成策略回报。

## 交易日历

`docs/data/research-calendar.json` 必须有 `source_url`, `verified_at`（含时区）, `coverage_start`, `coverage_end`, `sessions`（升序唯一YYYY-MM-DD）。用交易所公布的休市安排核验；不是把现有行情档案当作交易日历。不越过覆盖期，不推测下一年度假期。临时停市需更新核实。日历缺失或尚未核验、到期行情缺失、输入价格无效时不评分，后续补齐再结算，不移动原定到期日。

## 防回写与校验

账本为JSON中append-only `events` 数组，事件带sequence、previous_hash、hash。部署CI还应与已有受信任提交做旧前缀比较，避免重写整条hash链：

```
python scripts/research_ledger.py --check --git-base <已有账本的受信任commit>
```

首次引入没有旧账本，可先仅 `--check`；后续必须前缀检查。hash链不是外部签名，不声称抵御仓库管理员篡改。错误更正应该新增版本和说明，不能删掉失误。

## 长期复盘边界

每日数据核查和到期结算；每周区分数据错误、解释错误、遗漏事件；每月候选版本在影子环境测试。未来训练/校准/验证按时间顺序，标签跨界须purge/gap；禁止随机划分泄漏、挑最好期限或回写旧判断。主指标始终分期限报告命中分子/分母和覆盖率，和始终偏强、动量符号基准使用相同可评分样本。样本少时不给可靠胜率；重叠5/20日结果不能当独立样本。后续概率模型须另加校准和可靠性曲线；当前不输出数值概率，不承诺准确率必然提高。
