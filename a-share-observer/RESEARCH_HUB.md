# 研究中心：信息架构与验收约束

## 核心工作流

用户在 14:45 附近做决策，但现有主数据为盘后归档。网页不得将收盘数据称为当日 14:45 已知事实。研究用于理解市场环境，不自动下单，不保证预测准确。

入口按任务分组，而非按数据源堆叠：

| 页面 | 回答的问题 | 最有用的表现方式 |
|---|---|---|
| 研究判断 | 当前如何理解大盘，未来观察什么？ | 有期限的结论、正反证据、条件情景、失效条件、数据缺口、冻结档案 |
| A 股市场 | 市场内部是否支持指数表现？ | 指数与广度同图、成交趋势、风格对照、历史回放 |
| 资金与机构 | 谁的动作已被证实，什么只是资金代理？ | 融资趋势、ETF 份额趋势、实名公告事件、报告期快照 |
| 外围与宏观 | 资金价格、商品及海外环境怎样传导？ | 分单位时间序列、共同基准对照、原值/代理明确隔离 |
| 政策与事件 | 什么已发布、何时生效、什么仍待发生？ | 正式政策/官方评论分层、7/30 天事件日历、未定日期观察清单 |
| 板块研究 | 哪些板块相对领先，内部是否广泛参与？ | 排名、相对收益、热力图、成分覆盖与趋势 |
| 个股风险 | 特定股票有哪些已知风险与证据缺口？ | 股票搜索、融资趋势、质押快照、公告事件、关联债券 |
| 异动线索 | 涨跌停及接力结构怎样演化？ | 接力时间轴、次日反馈、逐日事件池 |
| 历史研究 | 历史样本与代表股表现如何？ | 保留既有对照功能；与前瞻研究评分分开 |

现有路由、控制器和 DOM 标识尽可能保留；资金与机构和外围与宏观迁移不得删去数据集。原研究日期与筛选维持联动。证据链接必须包含固定交易日及目标位置，不仅打开最新首页。

## 数据与时点

每条研究依据必须有可追溯来源、资料期、发布日期、抓取时间及可得时间；修订版本独立记录。发布日期未知的资料不得伪装成历史当时已知的信息。季报持仓日期不是公告日期，ETF 份额不能推出特定机构买卖。数据缺失、过期、来源失败、代理口径分别显示。

预测输入和历史引用冻结，不能事后修改当时依据。事后修订与原记录建立关联。历史回放重建的判断标记为重建，绝不计入前瞻命中率。

## 可验证研究与复盘

主要研究目标固定为沪深 300 未来 5 个交易日，1/20 日辅助单独评价。已知收盘价可作指数变化基准，但不是发布后实际成交收益。判断展示支持和反对证据、条件及失效信号，不将市场状态等同于未来涨跌。

未到期、不可评分、主动不判断分开。记录样本量、分母、覆盖率、基准和期限；不同期限不混算。重叠窗口不得当作独立样本宣称统计显著。无足够成熟前瞻样本时明确“尚未验证”，不用随意分数包装成上涨概率。

模型版本冻结。优化依据长期前瞻误差及分情景表现；候选规则先影子测试。训练与验证按时间切分并隔离跨边界标签；不通过回改旧判断提高成绩。自动任务只能增加后续结果、候选说明及新记录，不能覆盖原预测。

## 迁移验收

1. 旧首页、个股查询、板块图、融资、ETF、原油、美债、人工核验披露、代表股及历史日期切换功能均保留。
2. 研究依据可到达指定页面、指定日期、指定锚点；不可用日期明确报错，不悄悄换最新。
3. 桌面与手机没有横向溢出；菜单、返回、反复切换和异步加载不串页。
4. 空数据或接口失败保持可见提示；未覆盖项不填零，不渲染为安全。
5. 运行 Python/JS 单测、静态构建及浏览器操作回归，检查实际截图后才称布局完成。
6. 本地构建、PR、线上部署状态分别报告；需要授权后才能合并及部署。
